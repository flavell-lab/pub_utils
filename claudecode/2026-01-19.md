## Session Checkpoint - 2026-01-19 (Config-Driven Assembly)

### Summary
Implemented config-driven molecular connectome assembly using TOML configuration files with a CLI runner script.

### Files Created
- `src/pub_utils/config.py` - Configuration module with dataclasses and validation
  - `AssemblyConfig`, `ReleaseConfig`, `ReceptorConfig`, `ConstraintConfig`, `OutputConfig` dataclasses
  - `load_assembly_config()` - Load TOML config files
  - `validate_config()` - Validate config, returns list of errors
  - `save_config()` - Serialize config back to TOML
  - `compute_config_hash()` - SHA256 hash for reproducibility tracking
  - `create_metadata_sidecar()` - Generate metadata JSON for outputs

- `scripts/assemble_connectome.py` - CLI runner
  - Usage: `python scripts/assemble_connectome.py [--validate-only] [-q] <config.toml>`
  - Calls `assemble_nt_connectome()` or `assemble_npp_connectome()` based on config
  - Applies structural constraints if enabled
  - Saves binary, count, per-pair matrices and metadata sidecar

- `configs/examples/nt_dopamine_example.toml` - Dopamine assembly example
  - Release: `reporter:Wang2024`

### Data Source Coverage Issue
The acetylcholine example shows 0 connections because `literature:Bentley2016` release data (`data/Bentley2016/NT_release_literature.csv`) only contains **monoamine genes**:
- cat-2 (dopamine synthesis)
- dat-1 (dopamine transporter)
- mod-5 (serotonin transporter)
- tbh-1 (octopamine synthesis)
- tdc-1 (tyramine synthesis)
- tph-1 (serotonin synthesis)

It does NOT include `unc-17` (vesicular acetylcholine transporter). For acetylcholine assemblies, use `reporter:Wang2024` which has unc-17, unc-25 (GABA), and eat-4 (glutamate).
